# AI Horror Studio V2.1 — 故事 + 时间轴 + AI 制作 + 批量生产

AI 恐怖短剧自动生产系统。V2.1 是**成片质量升级**：在不引入图生视频的前提下，
把「画面太假 / 节奏太慢 / 声音出戏 / 故事无聊」四个问题逐条解决。

### V2.1 质量升级（本版重点）

**剧本：先结构，再镜头**
- 剧本按「钩子 → 建置 → 升级 → 反转 → 余味」组织；第 1 镜必须是全场最有冲击力的画面（前 3 秒留人）
- 新增**角色卡 / 场景卡**（`characters` / `scenes`）：固定外貌、服装、光线、色调，
  每次出图都原样带上，同一角色跨镜头才长得一样
- 每镜旁白上限 15 字；**每 3 镜至少留 1 镜没有旁白**，用画面说话
- 每镜标注运镜方向（推近 / 拉远 / 左移 / 右移 / 对角推 / 静止），画面节奏 1.5~4 秒

**画面：不再是「静态 PPT」**
- 运镜幅度 6% → 12%，新增左右平移与对角推（「镜头属性 → 运镜」里逐镜选择）
- 转场：硬切 / 黑场淡入淡出 / 短淡入淡出 / 白闪（按运镜自动分配，也可逐镜手改）
- 成片后处理：冷 / 暖 / 中性调色 + 胶片颗粒 + 暗角 + 轻锐化（导航栏「胶片风格」「暗角」「胶片颗粒」）
- 字幕字号按画面高度自动缩放（竖屏 1080×1920 → 48 号，自动断行 + 半透明底条 + 粗描边）
- 默认出图模型改为 Z-Image-Turbo（原生竖屏 928×1664），AI 设置里仍可切回免费的 Kolors
- 出图不再无条件放大：源图小于画幅时居中 + 补边，交给渲染端处理，避免「先糊后锐」

**节奏：画面优先**
- 镜头时长以剧本给出的画面节奏为准（1.5~4 秒），旁白塞不下才自动延长（最多 8 秒），
  界面上提示哪几镜旁白偏长，建议精简
- 配音改为「逐句说话」，先裁掉 TTS 首尾静音、再开始计时，不再把 1 秒多的死寂算进镜头
- 导航栏「节奏模式」可切回「旁白优先」（旧行为）；AI 制作页「⏱ 节奏重排」按剧本一键重排

**声音**
- 整条旁白音轨与成片统一响度到 -16 LUFS（短视频平台常用），不同音色拼在一起不再忽大忽小
- 有 BGM 时旁白自动「侧链压低」BGM，旁白间隙自动回升；没有 BGM 时自动垫一层低频 drone（可关）
- 轻混响，避免干声贴脸
- 配音语气按题材细分（民俗 / 都市 / 克苏鲁 / 心理），默认自动识别，AI 设置里可固定

**其它**
- 批量生产同样享受以上全部升级，配音语气按每个项目的题材自动选择
- 修复：Windows 上 FFmpeg 路径为大写 `.EXE` 时读取时长的探测失败

双击 `start.bat`，或在项目根目录执行：


## 3. 配置 AI（DeepSeek）

1. 打开 <https://platform.deepseek.com>，注册后在 **API keys** 页面创建一个 Key（`sk-...`）。
2. 软件右上角点 **「AI 设置」** → 粘贴 Key → 选模型 → **测试连接** → **保存**。
3. Key 保存在 `C:\Users\<你>\.ai_horror_studio\ai.json`，不在项目目录里；
   也可以用环境变量 `DEEPSEEK_API_KEY`（优先级高于本地配置）。

| 模型 | 说明 |
|---|---|
| `deepseek-flash` | 默认，速度快、便宜，适合分镜生成 |
| `deepseek-v4-pro` | 更会写故事，更慢更贵 |

计费按 token，生成一次 8 镜脚本大约几分钱人民币级别。

## 3.1 配置 AI（硅基流动 · 出图 + 配音）

1. 打开 <https://cloud.siliconflow.cn>，注册后进入 **API 密钥** 页面创建 Key。
2. 软件右上角点 **「AI 设置」** → 在「② 硅基流动」里粘贴 Key → 选「出图模型」「配音音色」
   → **测试硅基流动（出图 + 配音）** → **保存**。
   （测试会真的各发一次极小请求：一张 1024×1024 低步数图 + 一句「测试」。）
3. Key 保存在 `C:\Users\<你>\.ai_horror_studio\siliconflow.json`（与 DeepSeek 的 `ai.json` 分开），
   不在项目目录里；也可以用环境变量 `SILICONFLOW_API_KEY`（优先级更高）。

**出图模型**

| 模型 | 说明 |
|---|---|
| `Kwai-Kolors/Kolors` | 默认，**免费**，速度快 |
| `Tongyi-MAI/Z-Image-Turbo` | 约 0.1 元/张，质量更好 |
| `Qwen/Qwen-Image` | 约 0.3 元/张，擅长画面里的文字 |

**配音**：模型固定为 `FunAudioLLM/CosyVoice2-0.5B`，音色可选
`claire / anna / bella / diana`（女声）与 `alex / benjamin / charles / david`（男声）。
语速可选 0.5x ~ 1.5x（慢 / 稍慢 / 略慢 / 标准 / 略快 / 稍快 / 快），
「AI 制作」页签和「AI 设置」里都能改，保存在 `siliconflow.json` 的 `voice_speed` 里。
默认在朗读前加一句恐怖旁白风格指令（低沉、克制、语速稍慢、句尾留白），
逐镜单次旁白上限 300 字。

## 4. 使用流程

### 4.1 从故事开始（V1.2）

1. 点右上角「新建项目」，选择保存目录、输入名称（默认「午夜纸人」）。
2. 切到 **「故事（AI）」** 页签，填写：
   - **题材关键词**：如「废弃医院、纸人、雨夜」，越具体越可控
   - **氛围 / 风格**：中式民俗恐怖、日式都市怪谈、克苏鲁、心理惊悚等
   - **分镜数量**：4 ~ 24（默认 8）
   - **额外要求**（可选）：如「结尾要反转」
3. 点 **「✦ 生成故事分镜」**，等待 10~40 秒。生成后：
   - 右侧表格列出每个分镜的画面描述 / 旁白 / 时长
   - 选中一行，可在下方编辑「画面」「旁白」「时长」，点「应用修改」
   - 可「在此后插入」「删除此镜」，再点「保存脚本」写回 project.json
4. 点 **「⇩ 导入时间轴（替换现有分镜）」** 或 **「追加到时间轴」**：
   - 所有分镜进入时间轴，状态为「待配图」
   - 旁白自动生成 `subtitles/story_narration.srt` 并设为项目字幕
5. 回到「编辑」页签：
   - 点「导入漫画图片」时，若有待配图镜头，图片会**按顺序自动补到这些镜头上**
   - 或用「批量配图」：选中一个起始镜头，再选一组图片，只填待配图的镜头
   - 也可以先不配图，直接渲染成「黑场 + 旁白字幕」的粗剪
6. 点左栏「开始成片渲染」——或继续走 4.3 的 AI 出图 + AI 配音。

### 4.3 AI 出图 + AI 配音 + 出片（V1.3）

前置：已配好硅基流动 Key，且时间轴上的分镜带「画面描述」（出图）与「旁白」（配音）。

1. 切到 **「AI 制作」** 页签，确认左下角 API 状态是 `✓ 硅基流动`。
2. **① 画面**：选出图模型 → 点 **「✦ 生成全部画面」**。
   - 只为「还没有画面」的镜头出图；勾选「重新生成已有 AI 画面」可全部重画
   - 进度显示在面板（`画面 3/8 · 正在生成…`），单个镜头失败会跳过并继续
   - 生成的图自动裁成项目画幅（默认 1080×1920），时间轴上标为绿色的「AI 画面」
   - 你也可以在「编辑」页签手动给某些镜头配图；手动图不会被「重新生成」覆盖
3. **② 配音**：选音色 → 选语速 → 点 **「♪ 生成全部旁白配音」**。
   - 语速决定配音多长，镜头时长会跟着配音自动调整（见下方「音画同步」）；
     想整体更慢或更快，改语速后勾选「重新生成已有配音」重跑即可
   - 逐镜合成，完成后**自动按配音长度对齐镜头时长**（见下方「音画同步」）
   - 随后**自动拼成旁白音轨**（`audio/voice_track.wav`），设为项目旁白，并重导字幕
   - 「配音时间轴预览」里绿条 = 该镜配音占镜头的比例
   - 「拼成旁白音轨」可手动重拼；「清除配音」清掉所有逐镜配音记录
4. **③ 成片**：点 **「▶ 直接出片（不配音）」**（有配音时会自动带上旁白音轨）。
   成片在 `项目/output/项目名_final.mp4`，可用「打开输出目录」查看。

**音画同步**：旁白视频的节奏应该由声音决定，所以默认勾选
**「自动按配音长度对齐镜头时长」**。配音生成后，每镜时长会被设为：

```text
镜头时长 = 120ms 起始留白 + 该镜配音实际长度
```

旁白说完就切下一镜，配音既不会被截断，镜头也不会干等。
画面（镜头时长）永远匹配配音的实际长度——改语速、换音色、改旁白文本，
重新生成配音后时长都会自动重新对齐。
时间轴上的时长是真实结果，可以之后手动再调（但过长会被再次对齐）。
没有配音的镜头保持原时长。字幕会按新边界重新导出，保持一致。

> 旧版（V1.3 初版）是「镜头时长固定、配音塞进去」：配音长于镜头会被截断。
> 如果你手动改了时长导致配音超长，预览会标黄「配音超长·会被截断」，
> 重新跑一次「生成全部旁白配音」（勾选自动对齐）即可修正。

手动导入的旁白音频（`audio/` 里的整条旁白）优先级高于 AI 拼接音轨。

### 4.4 批量生产多个项目（V2.0）

前置：DeepSeek Key 与硅基流动 Key 都已配置好（批量要跑完整条流水线）。

1. 切到 **「批量（AI）」** 页签（Ctrl+4）。
2. **选择输出目录**：每个项目会在该目录下建一个同名子目录，结构与本软件的项目一致。
3. **编排任务清单**：在下方编辑器填「项目名 / 镜头数 / 题材关键词（必填）/ 风格 / 补充要求」，
   点 **「＋ 添加/更新」**。选中表格行可再次编辑（同名即更新），也可删除、上下移调整顺序。
   清单会自动保存，下次打开软件还在。
4. **选出片尺寸**：正式出片用「项目默认」；先试跑／看重效果可选 360×640，渲染快数倍。
5. 点 **「▶ 开始批量生产」**，确认后开始。表格状态依次为：
   `等待 → 进行中（说明列显示当前步骤）→ ✓ 完成 / ✗ 失败`，
   右侧日志按时间顺序记录每个项目的开始、步骤、结果。
6. 完成后选中某行点 **「打开选中成片」**（或双击该行）直接播放成片。

每个项目的流水线与 4.3 完全一致（同样的出图模型、音色、语速、自动对齐规则），
所以批量产出的成片与单项目手动做的效果相同。

**失败隔离**：

| 失败位置 | 结果 |
|---|---|
| 建项目（目录已存在等） | 该项目标记为 ✗，整批继续 |
| 生成故事 / 导入分镜 | 该项目标记为 ✗，整批继续 |
| 单个镜头出图失败 | 该镜渲染为黑场，项目仍 ✓（说明列注明） |
| 单个镜头配音失败 | 跳过该镜配音，项目仍 ✓（说明列注明） |
| 渲染失败 | 该项目标记为 ✗，整批继续 |

「停止」按钮只会在**当前项目跑完之后**生效：正在生成的素材不会被半途丢弃，
尚未开始的项目标记为「已停止（未运行）」。

> 批量会真实调用 DeepSeek 与硅基流动并按量计费。开始前软件会弹确认框，
> 列出项目数与总镜头数，先确认再跑。

### 4.2 从图片开始（V1.1 流程）

1. 新建/打开项目。
2. 左栏「导入漫画图片」多选图片；每张图片按「新导入图片默认时长」生成一个镜头。
3. 在时间轴或分镜列表中选中镜头，右栏可改：
   - **时长**：输入 3.5 或 00:03.50，或用 −0.5 / +0.1 等按钮；上下方向键 ±0.1s
   - **运镜**：静止 / 缓慢推近 / 缓慢拉远（成片中以 zoompan 实现）
   - **过渡**：硬切 / 黑场淡入淡出
4. 需要的话导入旁白、背景音乐、SRT 字幕（字幕会叠加在预览上，并在成片中烧录）。
5. 点左栏「开始成片渲染」，成片输出到 `项目/output/项目名_final.mp4`。

## 6. project.json（schema_version 2）

```json
{
  "schema_version": 2,
  "name": "午夜纸人",
  "created_at": "2026-11-03T14:30:00",
  "settings": {"width": 1080, "height": 1920, "fps": 30, "fit": "contain"},
  "shots": [
    {
      "id": "a1b2c3d4",
      "image": "images/01.png",
      "start": 0.0,
      "duration": 3.5,
      "zoom": "none",
      "transition": "cut",
      "subtitle": null,
      "scene": "灵堂里的纸人，雨夜，青灰色调",
      "narration": "那晚它一直在看着我。",
      "story_index": 1,
      "ai_image": "images/ai_a1b2c3d4.png",
      "voice": "audio/voice_a1b2c3d4.wav",
      "voice_ms": 2140
    }
  ],
  "story": {
    "schema_version": 1,
    "title": "雨夜纸人",
    "logline": "一场葬礼后，纸人开始替死人说话。",
    "keywords": "纸人、雨夜",
    "generated_at": "2026-11-03T15:02:00",
    "model": "deepseek-flash",
    "shots": [
      {"index": 1, "scene": "灵堂里的纸人", "narration": "那晚它一直在看着我。", "duration": 3.5}
    ]
  },
  "narration": "audio/voice_track.wav",
  "voice_track": "audio/voice_track.wav",
  "music": "audio/bgm.mp3",
  "subtitle": "subtitles/story_narration.srt",
  "images": ["images/01.png"],
  "total_duration": 3.5
}
```

- `shots` 是时间轴唯一事实来源，`start` 按顺序自动累加（reflow），不要手改。
- `shot.image` 可以为 `null`（故事已导入、画面待生成），渲染时按黑场处理。
- `scene` / `narration` / `story_index` 只为故事分镜提供，图片导入的镜头没有。
- `story` 是脚本草稿（可反复导入），与时间轴互不影响；`story.generated_at` 为生成时间。
- 打开 V1.0 项目时，`images` + `image_duration` 会自动迁移为 shots 并回写磁盘；
  旧 `images` 字段保留只读。
- `zoom`：`none` / `in` / `out`；`transition`：`cut` / `fade`。
- V1.3 字段（缺失时自动补 `null`，旧项目无需迁移）：
  - `shot.ai_image`：AI 生成的画面（同时也写进 `shot.image`），用于「重新生成」时区分手动配图
  - `shot.voice` / `shot.voice_ms`：该镜头的 AI 配音片段与时长
  - `voice_track`：逐镜配音按镜头起点拼出的整条旁白音轨；
    渲染时 `narration`（手动旁白）优先，其次 `voice_track`
  - `voice_offset_ms`：配音在镜头内的起始留白（默认 120ms，项目级）；
    `fit_durations_to_voice` 按 `镜头时长 = offset + 配音长度` 重排时长

## 8. 当前版本限制

- 时长只有「镜头级」，还不能对单镜头叠加多张图/多轨音频。
- 运镜只支持固定中心点推拉，尚无关键帧。
- 预览为近似效果（Tk 合成），运镜和过渡以 FFmpeg 渲染结果为准。
- 视频输入（「图片转视频」素材直接进时间轴）尚未支持。
- 字幕按全片烧录；导入故事会自动生成旁白字幕，暂不支持逐句手工对齐。
- AI 出图一次只画一张，不支持图生图 / 参考图；重画即覆盖旧 AI 画面。
- AI 配音为整镜一条，不支持逐句重录或单句换音色。
- 自动对齐按「配音长度」调整镜头，不支持手动指定某镜头的额外停留时长
  （可临时关掉勾选后再手动改）。
- 批量生产按项目串行执行（同一时刻只跑一个项目）。
- 批量不会覆盖输出目录里已有的项目：同名项目会被标记为「✗ 建项目失败」，
  需要重跑请先改名或把旧项目移走。也不支持断点续跑，重跑会从头开始。
- 批量不支持每个项目使用不同的出图模型 / 音色 / 语速；这些统一沿用
  「AI 制作」页签与「AI 设置」里的当前选择。
- **V2.1 计划**：AI 视频（图生视频）。
